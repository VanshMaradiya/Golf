# 🏌️ Golf Management System

A full-stack Golf Management System built using **Python (Flask)**, **PostgreSQL**, **HTML**, **CSS**, and **JavaScript**.

This project provides:

- Login & Register
- Admin Panel
- Player Panel
- Courses & Holes
- Tournaments
- Score Entry
- Professional UI
- Role Based Access (Admin / Player)

This is a learning + portfolio project.

---

## 📌 Features

### ✅ Authentication
- Register (Admin / Player)
- Login
- Logout
- Role based access control

### ✅ Admin Panel
- Create golf courses
- Add holes to courses
- Create tournaments
- Set tournament status (ongoing / upcoming / completed)

### ✅ Player Panel
- View tournaments
- Select tournament
- Add hole scores


## 🛠 Tech Stack

### Backend
- Python
- Flask

### Frontend
- HTML
- CSS
- JavaScript (Fetch API)

### Database
- PostgreSQL
